# ROBOT-COMM-SECURE v2.0

**Безопасный криптографический протокол межроботового взаимодействия (M2M) для организации систем взаимопомощи.**

[![Platform Version](https://shields.io)](https://github.com)
[![License: MIT](https://shields.io)](https://opensource.org)

## 📖 О проекте

**ROBOT-COMM-SECURE** — это открытый стандарт и библиотека для микроконтроллеров, реализующая протокол экстренной связи между автономными роботами. Проект разработан как технологический базис для гипотетического **Глобального Реестра Сертифицированных Роботов**.

Если один робот попадает в аварийную ситуацию (блокировка приводов, критический разряд, потеря ориентации), он начинает транслировать аппаратно защищенный бинарный SOS-пакет по двум независимым каналам: **Bluetooth Low Energy (BLE Advertising)** и направленный **ИК-порт**.

## 🏗 Архитектура безопасности

В отличие от классических систем, протокол не использует текстовые команды (что исключает инъекции кода) и базируется на трех уровнях защиты встроенных систем:

1. **Hardware Integrity (CRC32):** Защита от физических искажений данных из-за солнца, оптики ИК-портов или радиопомех.
2. **Anti-Replay Protection (Timestamp/Nonce):** Защита от перехвата и повторного воспроизведения старых пакетов злоумышленниками.
3. **Cryptographic Trust (HMAC-SHA256 / mbedTLS):** Проверка подлинности робота по токену авторизованного реестра. Несертифицированные устройства не могут заспамить или обмануть сеть роботов.

## 🚀 Быстрый старт

### Предварительные требования
* **ESP-IDF v4.4+** или v5.x
* Две платы разработки на базе **ESP32** / **ESP32-S3** / **ESP32-C3**
* Подключенный ИК-трансивер к пинам UART

### Клонирование и сборка
```bash
git clone https://github.com
cd robot-comm-secure

# Конфигурация под вашу архитектуру
idf.py set-target esp32
idf.py build
idf.py -p [ВАШ_ПОРТ] flash monitor
```

## 💻 Пример использования (Робот в беде)

```c
#include "robot_secure_comm.h"

void app_main(void) {
    robot_sos_packet_t my_packet;
    
    // Сборка бинарного пакета взаимопомощи
    robot_packet_pack(&my_packet, 987654321, ROBOT_EVENT_MECHANICAL_MESS, 1771122334, 0);
    
    // Криптографическое подписание ключом реестра
    robot_packet_sign(&my_packet, "MY_SECRET_KEY", 13);
    
    // Передача по ИК и BLE-радиоканалу
    transport_ir_init(1, 17, 16, 115200);
    transport_ir_send(1, &my_packet);
    transport_ble_init(&my_packet);
}
```
